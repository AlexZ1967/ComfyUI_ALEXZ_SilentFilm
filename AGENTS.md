- Общайся с пользователем по-русски; identifiers и названия API оставляй на английском.
- Docstring функций пиши на английском, комментарии и документацию проекта — на русском.

- Для локальных Python-проверок используй Conda environment `p313-torch214-cu132`.
- Сохраняй существующие `class_type`, имена входов/выходов, метаданные и сериализованные контракты workflow.

- Перед frontend-релизом runtime bundle создаётся из `frontend/src/`; `web/generated/` вручную не редактируется.
