# Происхождение кода

Silent Film выделен из проекта [AlexZ1967/ComfyUI_ALEXZ_tools](https://github.com/AlexZ1967/ComfyUI_ALEXZ_tools).

Базовый коммит перед выделением: `db1ced441010a6541f57674049084590d230ad0c` («Пропускать выключенные дефекты и использовать NVENC»).

История разработки перенесённых нод, утилит, frontend, тестов, руководств и workflow-примеров до выделения хранится в исходном репозитории. Авторство исходного кода сохраняется; самостоятельный репозиторий начинает историю с адаптированной копии этих файлов.

При выделении изменены регистрация пакета, импорты, пути тестов и сборки. Публичные идентификаторы нод, входы/выходы и формат `film_json` сохранены. В новый пакет добавлены локальный реестр, объявления типов ComfyUI, инструкции разработчика и browser smoke.

Общие средства ALEXZ_tools — Module Node Picker, сохранение workflow и обновления — продолжают развиваться в исходном репозитории. Пользовательские рабочие workflow не включаются в перенос автоматически.
